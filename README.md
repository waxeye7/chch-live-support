# chch live — Support

**chch live** is the iOS companion app for [chch.live](https://www.chch.live): what's happening in Christchurch today — the civic feed, live buses and stop ETAs, the city's pulse, and reports near you.

## Help

- No account is needed — everything works on first launch.
- The **Nearby** tab uses your device's location to find reports near you. It only runs when you allow location access, and falls back to Cathedral Square otherwise.
- Live bus and arrival data comes from Metro / ECan realtime feeds via the chch.live API.
